Perjalanan satu semester

13 pertemuan, dari kenalan sampai pamer alat buatan sendiri.

  • Kenalan
  • Logika
  • Web
  • IoT & rakit alat
  1. P1

    Kenalan ekskul & IoT

    Lihat contoh Smart Dustbin, Smart Locker, dan Smart Room Monitor.

  2. P2

    Siapkan alat coding

    Pasang tools, lalu lihat demo alat Smart Room Monitor.

  3. P3

    Logika blok: urutan & variabel

    Menyusun program pakai block coding.

  4. P4

    Logika blok: kondisi

    Program yang bisa memilih dengan if.

  5. P5

    Halaman HTML pertama

    Tag, heading, dan paragraf.

  6. P6

    HTML lanjutan

    List, gambar, dan link.

  7. P7

    CSS dasar

    Warna, teks, dan jarak.

  8. P8

    Selesaikan profil diri

    Review HTML + CSS, waktu mengejar yang tertinggal.

  9. P9

    Kenal ESP32 & breadboard

    Rakit rangkaian LED, belum pakai coding.

  10. P10

    Arduino IDE & Blink

    Pasang IDE, board ESP32, library DHT, lalu upload Blink.

  11. P11

    Sensor suhu DHT22

    Rakit 3 kabel, baca suhu di Serial Monitor & Plotter. Ada Kartu Sabotase.

  12. P12

    Data tampil di dashboard

    ESP32 kirim data lewat WiFi, lalu kustom nama, judul, dan warna dashboard.

  13. P13

    Showcase

    Foto kelompok, rumah alat dari kardus, dan pamerkan hasilnya.

Di P10 sampai P13 tiap pertemuan ada 3 challenge: Easy +5, Medium +10, Hard +15, aktif tanya jawab dapat +2, dan tidak ada PR.
