- D. <h6>

**2. Struktur dasar HTML terdiri dari html, head, dan...**
- A. <body>
- B. <footer>
- C. <style>
- D. <script>
- E. <code>

**Jawaban: A**

**3. Manakah pernyataan yang benar tentang tag penutup?**
- A. Semua tag wajib punya penutup tanpa kecuali
- B. Sebagian tag seperti <img> tidak butuh tag penutup
- C. Tag penutup tidak pernah dipakai di HTML
- D. Tag penutup hanya untuk CSS
