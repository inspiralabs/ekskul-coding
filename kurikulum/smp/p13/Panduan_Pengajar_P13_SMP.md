Nomor slide = nomor di PPT (slide 1 = Linktree). Bahan lengkap, kunci & rubrik: `sumber/Materi_Ajar_P13_SMP_InspiraLabs.md`.

> Prinsip hari ini: **tidak ada kode baru, tidak ada rakitan baru.** Foto kelompok dipasang, alat dimasukkan ke kardus sederhana ("rumah alat"), diuji ulang, dipamerkan, dan folder website diserahkan. ## 1. Tujuan pertemuan (yang bisa dilihat)

Di akhir kelas, setiap kelompok/individu:
1. Menunjukkan dashboard dengan `foto-kelompok.jpg` tampil dan angka sensor tetap muncul.
2. Menunjukkan alat di dalam rumah alat berlabel Device ID, menyala dengan power bank, dan dashboard berubah saat sensor ditiup.
3. Presentasi ±1 menit dengan 3 kalimat sakti + demo tiup sensor, lalu menyerahkan `smp-XX.zip` (≤ 5 MB).

## 5. Gaya mengajar: belajar sambil bermain

- **Hari terakhir = semangat tinggi, fokus rendah.** Pakai timer besar di proyektor untuk setiap blok. Umumkan "5 menit lagi" sebelum blok berakhir.
- **Fungsi dulu, hias belakangan.** Urutan rumah alat: sensor dekat lubang → lubang USB → label → hiasan (kalau sempat). Tidak ada hiasan yang dibawa pulang sebagai tugas.
- **Showcase seperti panggung:** sambut tiap kelompok dengan nama alatnya ("Silakan, Smart Room Monitor Kelompok Elang!"), tepuk tangan setiap selesai.
- **Siswa malu presentasi:** boleh membaca dari kertas; boleh berdiri di samping teman. Jangan dipaksa sendirian di depan. Tutor bisa memancing: "Alat kalian namanya apa?"
- **Penonton aktif:** setiap pertanyaan dari penonton +2, supaya mereka tetap memperhatikan.
- **Peran:** Fotografer (foto & kecilkan), Perakit (memasukkan alat ke rumah), Desainer (hias & label), Presenter (pimpin latihan 3 kalimat). Saat showcase **semua anggota bicara minimal 1 kalimat**: kelompok 4 → 3 kalimat + 1 orang demo tiup; kelompok 2 → satu orang 2 kalimat.
- **Peserta individu:** pegang semua peran, presentasi sendiri. Latihan Medium berpasangan dengan individu lain. Beri pujian khusus untuk kemandirian.

## 8. Kesalahan yang sering terjadi & cara membantu

| Kesalahan | Pertanyaan pancingan |
|---|---|
| Foto tidak muncul | "Nama filenya persis? Huruf besar? Akhirannya `.jpg` atau `.jpeg`? Foto ada di folder yang sama dengan `index.html`?" |
| `foto-kelompok.jpg.jpg` | Nyalakan View → **File name extensions** di File Explorer, lalu "Sekarang namanya apa?" |
| Sensor ditempel berdempetan dengan ESP32 | "Pegang ESP32-nya sebentar. Hangat? Apa akibatnya untuk sensor di sebelahnya?" |
| Lubang USB terlalu sempit, kabel tertekuk | "Kalau kabelnya tertekuk terus, lama-lama apa yang terjadi?" |
| Kabel tercabut saat memasukkan ke kotak | "Dashboard masih jalan? Kalau tidak, Serial Monitor bilang apa?" |
| Kabel out pindah dari D4 saat merapikan | "Kabel kuning sekarang di pin apa? Program menunggu di pin berapa?" |
| Tidak ada label Device ID | "Kalau 13 kotak dikumpulkan di meja tutor, bagaimana tahu yang mana punya kalian?" |
| Video/foto asli HP ikut (zip puluhan–ratusan MB) | "Klik kanan folder → Properties. Berapa ukurannya? Batasnya berapa?" |
| Lupa api.js asli / sudah diubah | "Boleh mengubah api.js?" → salin `api.js` dari zip asli |

## 9. Troubleshooting cepat

| Gejala | Penyebab paling mungkin | Tindakan |
|---|---|---|
| Dashboard tidak update setelah masuk kotak | Kabel tercabut | Buka kotak, colok laptop, baca Serial Monitor (tabel P12) |
| `Gagal baca sensor` kadang-kadang | Kabel tertekan tutup / setengah lepas | Rapikan jalur kabel, tekan sampai mentok |
| Suhu 1–3°C lebih tinggi dari kelompok lain | Sensor dekat ESP32 / kotak tertutup rapat | Pindah sensor ke dekat lubang, tambah lubang ventilasi |
| ESP32 sering restart | Kabel USB tertekuk / power bank lemah | Perlebar lubang, ganti power bank |
| Breadboard bergeser | Tidak ditempel | Double tape di bawah breadboard |
| Foto kotaknya hilang dari dashboard | Nama file salah / foto di luar folder | Cek nama persis & lokasi (sebelah `index.html`) |
| Proyektor tidak menampilkan data | WiFi laptop tutor / tab lama | Refresh tab; pakai laptop kelompok itu |
| Zip > 5 MB | Foto/video besar | Hapus video, resize foto ke lebar 800 px, zip ulang |

## 10. Keselamatan

- **Cutter hanya dipegang tutor.** Siswa menandai lubang dengan spidol, tutor yang memotong. Gunting boleh dipakai siswa.
- **Tidak pakai lem tembak** (panas) di dekat board atau sensor. Pakai double tape/selotip.
- **Tidak ada logam/aluminium foil/kaleng** di dalam kotak: kaki pin bisa korsleting.
- Cabut USB sebelum memindah kabel atau menempel board.
- Uji Goyang: goyang **pelan**, jangan dilempar/dibanting.
- Power bank yang panas atau menggembung jangan dipakai.
- Foto/video showcase hanya dipakai sesuai izin sekolah. Jangan tulis nomor HP/alamat di website.

## 11. Diferensiasi

- **Siswa cepat:** Challenge Hard (Uji Goyang); rumah alat lebih rapi (jendela sensor, label kabel); bantu kelompok lain **dengan memberi saran**; bonus: isi kotak `.kotak-kosong` di dashboard dengan kalimat sendiri sebelum zip.
- **Siswa kesulitan:** target minimum: foto tampil (atau foto alat), alat di kardus sederhana dengan lubang USB + sensor menghadap keluar + label Device ID, menyala dengan power bank. Presentasi boleh membaca dari kertas. Tutor membantu memeriksa folder sebelum zip.
